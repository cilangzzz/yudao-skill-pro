# OA 通讯录接口 (OaContactController)

> OA 外部联系人管理：用户维护个人外部联系人（客户/供应商等），支持按个人分类管理、以"共享关系"为中心的多人持有模型（创建人与接收人均通过持有关联访问联系人，最后一人移除后才删除正文），并支持共享给我的/我共享的/我的联系人三个查询视角。

## 接口路径前缀

/oa/contact  (Controller: OaContactController)
/oa/contact-category  (Controller: OaContactCategoryController)

## 1. 外部联系人（OaContactController）

### 1.1 创建外部联系人

- **路径**: POST /oa/contact/create
- **权限**: oa:contact:create
- **说明**: 创建外部联系人，并将当前登录用户作为首个持有人写入共享关系（标记为已处理），使其直接进入"我的联系人"。

**请求参数 (OaContactSaveReqVO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| id | Long | 否 | - | 联系人编号（新增时不传） |
| categoryId | Long | 否 | - | 分类编号（本人分类，传值时校验归属） |
| name | String | 是 | @NotBlank、@Size(max=50) | 姓名 |
| sex | Integer | 否 | - | 性别 |
| mobile | String | 是 | @NotBlank、@Mobile、@Size(max=20) | 手机号码 |
| email | String | 是 | @NotBlank、@Email、@Size(max=100) | 邮箱 |
| address | String | 否 | @Size(max=255) | 地址 |
| companyName | String | 否 | @Size(max=100) | 公司名称 |
| companyPhone | String | 否 | @Size(max=30) | 公司电话 |
| avatar | String | 否 | @Size(max=512) | 头像地址 |
| remark | String | 否 | @Size(max=500) | 备注 |

**响应**: CommonResult&lt;Long&gt; —— 联系人编号。

**业务逻辑**:
1. 若传入分类编号，校验该分类属于当前登录用户（否则抛出分类不存在错误）。
2. 将请求 VO 转换为 DO，并根据姓名生成拼音（pinyin）后插入联系人表。
3. 为创建人本人插入一条持有共享关系（handleStatus=true、携带本人分类），创建人与接收人均通过该关联持有联系人，删除时只移除本人关联，最后一人移除后才删除正文。
4. 返回新联系人编号。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_002 | 联系人分类不存在（分类不属于当前用户） |

### 1.2 更新外部联系人

- **路径**: PUT /oa/contact/update
- **权限**: oa:contact:update
- **说明**: 更新外部联系人，仅允许创建人本人操作，并同步本人持有关系上的分类。

**请求参数 (OaContactSaveReqVO)**: 同 [1.1 创建外部联系人](#11-创建外部联系人)，其中 `id` 必传。

**响应**: CommonResult&lt;Boolean&gt; —— 是否成功。

**业务逻辑**:
1. 校验联系人存在且当前用户有访问权限（通过本人持有关联校验）。
2. 进一步校验联系人的创建人（creator）为当前登录用户，否则抛出无权访问错误。
3. 若传入分类编号，校验该分类属于当前用户。
4. 转换为 DO 并重新生成拼音，调用 `updateForSave` 更新联系人。
5. 查询当前用户在该联系人上的持有关系，同步更新其分类编号。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_000 | 联系人不存在 |
| 1_054_130_001 | 无权访问该联系人（非创建人） |
| 1_054_130_002 | 联系人分类不存在 |

### 1.3 删除外部联系人

- **路径**: DELETE /oa/contact/delete
- **权限**: oa:contact:delete
- **说明**: 创建人删除自己创建的外部联系人；实际为移除本人持有关联，最后一个持有人离开时才删除联系人正文。

**请求参数**: 无（Query 参数）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| id | Long | 是 | @RequestParam 必传 | 联系人编号 |

**响应**: CommonResult&lt;Boolean&gt; —— 是否成功。

**业务逻辑**:
1. 校验联系人存在且当前用户有访问权限。
2. 校验当前用户为联系人创建人，否则抛出无权访问错误。
3. 复用"删除接收到的共享联系人"逻辑：删除本人的持有关联。
4. 若该联系人已无任何持有关联，则删除联系人正文。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_000 | 联系人不存在 |
| 1_054_130_001 | 无权访问该联系人（非创建人） |

### 1.4 共享外部联系人

- **路径**: POST /oa/contact/share
- **权限**: 已认证（登录即可，无独立权限标识）
- **说明**: 将自己持有（含接收到的共享）的联系人共享给其他用户，接收人初始为"未处理"状态，且接收人可再次转共享。

**请求参数 (OaContactShareReqVO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| contactId | Long | 是 | @NotNull | 联系人编号 |
| userIds | List&lt;Long&gt; | 是 | @NotEmpty；元素 @NotNull | 共享接收人用户编号列表 |

**响应**: CommonResult&lt;Boolean&gt; —— 是否成功。

**业务逻辑**:
1. 通过"获得联系人详情"的校验逻辑确认当前用户持有该联系人（接收人也可以再共享）。
2. 校验共享接收人用户均存在（system 模块 AdminUserApi，失败时抛出用户不存在错误 1_002_003_003）。
3. 查询该联系人已有的持有关联，过滤出尚未持有的接收人（排除当前用户本人），若无新增则直接返回。
4. 批量插入新的共享关系，处理状态初始为未处理（handleStatus=false）。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_000 | 联系人不存在 |
| 1_054_130_001 | 无权访问该联系人（当前用户未持有） |
| 1_002_003_003 | 用户不存在（共享接收人校验失败，来自 system 模块） |

### 1.5 删除接收到的共享联系人

- **路径**: DELETE /oa/contact/delete-received
- **权限**: 已认证（登录即可，无独立权限标识）
- **说明**: 移除当前用户在该联系人上的持有关联；最后一个持有人离开时删除联系人正文。

**请求参数**: 无（Query 参数）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| contactId | Long | 是 | @RequestParam 必传 | 联系人编号 |

**响应**: CommonResult&lt;Boolean&gt; —— 是否成功。

**业务逻辑**:
1. 校验联系人存在。
2. 查询当前用户在该联系人上的持有关联，不存在则抛出无权访问错误。
3. 删除该持有关联。
4. 若该联系人已无任何持有关联，则删除联系人正文。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_000 | 联系人不存在 |
| 1_054_130_001 | 无权访问该联系人（未持有该联系人） |

### 1.6 处理外部联系人共享

- **路径**: PUT /oa/contact/handle-share
- **权限**: 已认证（登录即可，无独立权限标识）
- **说明**: 共享接收人处理收到的共享：确认接收并选择本人分类，处理状态置为已处理（进入"我的联系人"）。

**请求参数 (OaContactHandleReqVO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| contactId | Long | 是 | @NotNull | 联系人编号 |
| categoryId | Long | 否 | - | 接收人分类编号（传值时校验归属） |

**响应**: CommonResult&lt;Boolean&gt; —— 是否成功。

**业务逻辑**:
1. 查询当前用户在该联系人上的持有关联，不存在则抛出无权访问错误。
2. 校验联系人存在；若当前用户是联系人创建人则拒绝（创建人的分类只能通过联系人编辑维护，不能仅修改初始化的持有关系）。
3. 若传入分类编号，校验该分类属于当前用户。
4. 更新该持有关联：处理状态置为已处理（handleStatus=true），并保存接收人选择的分类。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_000 | 联系人不存在 |
| 1_054_130_001 | 无权访问该联系人（未持有，或为创建人本人） |
| 1_054_130_002 | 联系人分类不存在 |

### 1.7 获得外部联系人详情

- **路径**: GET /oa/contact/get
- **权限**: oa:contact:query
- **说明**: 获得外部联系人详情，所有用户均通过本人持有关联校验访问权限，响应附带共享记录与共享人/接收人信息。

**请求参数**: 无（Query 参数）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| id | Long | 是 | @RequestParam 必传 | 联系人编号 |

**响应**: CommonResult&lt;OaContactRespVO&gt;

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | Long | 联系人编号 |
| ownerUserId | Long | 创建人用户编号 |
| ownerUserName | String | 创建人用户昵称 |
| categoryId | Long | 分类编号 |
| categoryName | String | 分类名称 |
| name | String | 姓名 |
| pinyin | String | 姓名拼音 |
| sex | Integer | 性别 |
| mobile | String | 手机号码 |
| email | String | 邮箱 |
| address | String | 地址 |
| companyName | String | 公司名称 |
| companyPhone | String | 公司电话 |
| avatar | String | 头像地址 |
| remark | String | 备注 |
| shares | List&lt;Share&gt; | 共享记录列表（仅展示当前登录用户本人发出的共享，不含初始化的本人关联） |
| share | Share | 当前行的共享关系，仅"我共享的"列表返回 |
| sharerName | String | 分享给当前用户的共享人昵称 |
| handleStatus | Boolean | 当前接收人的处理状态 |
| sharedCategoryId | Long | 当前接收人的分类编号 |
| sharedCategoryName | String | 当前接收人的分类名称 |
| createTime | LocalDateTime | 创建时间 |

其中 Share 子结构：

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | Long | 共享记录编号 |
| userId | Long | 共享接收人用户编号 |
| creatorName | String | 实际共享人昵称 |
| userName | String | 共享接收人用户昵称 |
| userAvatar | String | 共享接收人用户头像 |
| categoryId | Long | 分类编号 |
| categoryName | String | 接收人的分类名称 |
| handleStatus | Boolean | 处理状态 |
| createTime | LocalDateTime | 共享时间 |

**业务逻辑**:
1. 校验联系人存在。
2. 查询当前用户在该联系人上的持有关联，不存在则抛出无权访问错误（所有用户均通过本人关联校验访问权限）。
3. Controller 拼接响应：批量查询该联系人的全部共享关系、创建人与接收人用户信息、相关分类，填充创建人昵称、分类名称、共享记录（仅展示本人发出且非本人接收的共享）、共享人昵称与当前用户的处理状态/共享分类。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_000 | 联系人不存在 |
| 1_054_130_001 | 无权访问该联系人（未持有该联系人） |

### 1.8 获得我的联系人分页

- **路径**: GET /oa/contact/my-page
- **权限**: oa:contact:query
- **说明**: 分页查询本人创建及已处理接收的联系人（即本人持有关联已处理且符合本人分类的联系人）。

**请求参数 (OaContactPageReqVO)**（继承 PageParam：pageNo/pageSize）:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| pageNo | Integer | 否 | 分页参数 | 页码 |
| pageSize | Integer | 否 | 分页参数 | 每页条数 |
| keyword | String | 否 | - | 姓名、拼音、手机或公司名称关键字 |
| categoryId | Long | 否 | - | 分类编号（按本人分类过滤） |
| handleStatus | Boolean | 否 | - | 是否已处理（本接口固定按"已处理"查询，该参数不生效） |
| alphabet | String | 否 | @Pattern(^[A-Z]?$) | 姓名拼音首字母，空字符串表示全部 |

**响应**: CommonResult&lt;PageResult&lt;OaContactRespVO&gt;&gt; —— 字段同 [1.7 获得外部联系人详情](#17-获得外部联系人详情)。

**业务逻辑**:
1. 查询本人已处理且符合本人分类的共享（持有）关系。
2. 取出关联的联系人编号集合，为空则返回空分页。
3. 按联系人编号集合与分页条件查询联系人分页。
4. Controller 按详情接口的拼接逻辑填充响应（共享记录、创建人/接收人信息、分类名称）。

### 1.9 获得共享给我的联系人分页

- **路径**: GET /oa/contact/received-page
- **权限**: oa:contact:query
- **说明**: 分页查询他人共享给当前用户的联系人（排除创建人初始化的本人关联），可按处理状态与本人分类过滤。

**请求参数 (OaContactPageReqVO)**: 同 [1.8 获得我的联系人分页](#18-获得我的联系人分页)；其中 `handleStatus` 在本接口生效：为空查全部，true/false 分别筛选已处理/未处理的共享。

**响应**: CommonResult&lt;PageResult&lt;OaContactRespVO&gt;&gt; —— 字段同 [1.7 获得外部联系人详情](#17-获得外部联系人详情)。

**业务逻辑**:
1. 按接收人（当前用户）、处理状态与分类查询本人的共享（持有）关系。
2. 过滤掉创建人初始化的本人关联（creator 等于当前用户的记录不是"收到的共享"）。
3. 取出关联的联系人编号集合，为空则返回空分页。
4. 按联系人编号集合与分页条件查询联系人分页。
5. Controller 按详情接口的拼接逻辑填充响应，接收人视角字段（sharerName/handleStatus/sharedCategoryId 等）来自当前用户的共享关系。

### 1.10 获得我共享的联系人分页

- **路径**: GET /oa/contact/shared-page
- **权限**: oa:contact:query
- **说明**: 分页查询当前用户发出的共享记录，每个接收人一行，可按本人分类过滤联系人。

**请求参数 (OaContactPageReqVO)**: 同 [1.8 获得我的联系人分页](#18-获得我的联系人分页)；`handleStatus` 在本接口不作为查询条件，按"本人仍持有"的联系人全量查询。

**响应**: CommonResult&lt;PageResult&lt;OaContactRespVO&gt;&gt; —— 字段同 [1.7 获得外部联系人详情](#17-获得外部联系人详情)；其中 `share` 字段返回当前行的共享关系（即该接收人一行对应的共享记录）。

**业务逻辑**:
1. 查询本人仍持有且符合本人分类的联系人编号集合，为空则返回空分页。
2. 按当前用户发出的共享关系分页查询，每个接收人一行。
3. 批量查询共享的联系人正文，按详情接口的拼接逻辑构建联系人响应 Map。
4. 逐行将联系人响应与该行的共享记录组装：从联系人的共享列表中取出当前行对应的共享记录，填入 `share` 字段返回。

## 2. 联系人分类（OaContactCategoryController）

### 2.1 创建联系人分类

- **路径**: POST /oa/contact-category/create
- **权限**: 已认证（登录即可，无独立权限标识）
- **说明**: 为当前登录用户创建个人联系人分类，同一用户下分类名称唯一。

**请求参数 (OaContactCategorySaveReqVO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| id | Long | 否 | - | 分类编号（新增时不传） |
| name | String | 是 | @NotBlank、@Size(max=50) | 分类名称 |
| sort | Integer | 是 | @NotNull | 显示排序 |

**响应**: CommonResult&lt;Long&gt; —— 分类编号。

**业务逻辑**:
1. 校验同一用户下分类名称唯一（否则抛出名称重复错误）。
2. 将请求 VO 转换为 DO 并设置归属用户为当前登录用户，插入分类表。
3. 返回新分类编号。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_003 | 联系人分类名称已存在 |

### 2.2 更新联系人分类

- **路径**: PUT /oa/contact-category/update
- **权限**: 已认证（登录即可，无独立权限标识）
- **说明**: 更新当前登录用户自己的联系人分类。

**请求参数 (OaContactCategorySaveReqVO)**: 同 [2.1 创建联系人分类](#21-创建联系人分类)，其中 `id` 必传。

**响应**: CommonResult&lt;Boolean&gt; —— 是否成功。

**业务逻辑**:
1. 校验分类存在且属于当前登录用户（否则抛出分类不存在错误）。
2. 校验同一用户下分类名称唯一（排除自身）。
3. 将请求 VO 转换为 DO，按 id 更新分类。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_002 | 联系人分类不存在 |
| 1_054_130_003 | 联系人分类名称已存在 |

### 2.3 删除联系人分类

- **路径**: DELETE /oa/contact-category/delete
- **权限**: 已认证（登录即可，无独立权限标识）
- **说明**: 删除当前登录用户自己的联系人分类，同时清空联系人及持有关系上对该分类的引用。

**请求参数**: 无（Query 参数）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| id | Long | 是 | @RequestParam 必传 | 分类编号 |

**响应**: CommonResult&lt;Boolean&gt; —— 是否成功。

**业务逻辑**:
1. 校验分类存在且属于当前登录用户。
2. 清空本人联系人（创建人视角）上的该分类编号，并清空持有（共享）关系上的该分类编号，不删除联系人或共享关系。
3. 删除联系人分类。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_002 | 联系人分类不存在 |

### 2.4 获得联系人分类

- **路径**: GET /oa/contact-category/get
- **权限**: oa:contact:query
- **说明**: 获得指定联系人分类详情，仅可查看本人分类。

**请求参数**: 无（Query 参数）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|-----|---------|------|
| id | Long | 是 | @RequestParam 必传 | 分类编号 |

**响应**: CommonResult&lt;OaContactCategoryRespVO&gt;

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | Long | 分类编号 |
| name | String | 分类名称 |
| sort | Integer | 显示排序 |

**业务逻辑**:

2. 转换为响应 VO 返回。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_130_002 | 联系人分类不存在 |
