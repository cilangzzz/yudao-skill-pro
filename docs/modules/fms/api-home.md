# 财务首页接口 (FmsHomeController)

> 提供 FMS 财务管理首页数据：按账套返回当期财务指标汇总与最近十二期指标趋势，并支持单个财务指标的明细查询（含最近十二期趋势和当期科目构成）。

## 接口路径前缀

/fms/home  (Controller: FmsHomeController)

## 1. 首页指标查询

### 1.1 获得首页

- **路径**: GET /fms/home/get
- **权限**: fms:home:query
- **说明**: 获得指定账套的首页数据，包括当前会计期间、当期财务指标数组以及最近十二期财务指标趋势。

**请求参数 (Query 参数)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| accountSetId | Long | 是 | @NotNull | 账套编号 |

**响应**: CommonResult&lt;FmsHomeRespVO&gt;

| 字段 | 类型 | 说明 |
|-----|------|------|
| currentMonth | String | 当前会计期间，格式如 `2026-08` |
| metrics | List&lt;Metric&gt; | 当期财务指标数组 |
| trends | List&lt;Trend&gt; | 财务指标趋势数组（最近十二期） |

Metric 结构：

| 字段 | 类型 | 说明 |
|-----|------|------|
| key | String | 指标标识，如 `income` |
| name | String | 指标名称，如 `收入` |
| amount | BigDecimal | 指标金额 |

Trend 结构：

| 字段 | 类型 | 说明 |
|-----|------|------|
| month | String | 会计期间 |
| metrics | List&lt;Metric&gt; | 该期动态财务指标数组 |
| income | BigDecimal | 收入 |
| operatingCost | BigDecimal | 成本 |
| profit | BigDecimal | 利润 |
| expense | BigDecimal | 费用 |
| other | BigDecimal | 其他 |

**业务逻辑**:
1. 校验当前用户对账套的读权限（账套不存在或无权限时抛出对应错误）。
2. 校验账套初始化状态：账套未完成初始化或未设置启用期间时，抛出 `ACCOUNT_SET_NOT_INITIALIZED`。
3. 确定当前会计期间（最近已结账期间的下一期，无结账记录时为账套启用期间），并查询账套下已启用的首页财务指标；历史账套未初始化指标时回退到内置五项指标（收入、成本、利润、费用、其他）。
4. 计算最近十二期财务指标趋势：早于账套启用期间的月份生成金额为 0 的空趋势；其余月份按期构建趋势。
5. 单期趋势计算：指标为行次公式（`L行次` 表达式）时，按指标类型查询当期利润表或资产负债表的行次数据并按公式汇总；科目公式则查询科目余额并按公式取数规则逐项计算后叠加。
6. 从当期指标中提取收入、成本、利润、费用、其他五项快捷金额填充到各期趋势。
7. 返回当前会计期间、当期指标数组（取最近一期趋势的指标）和十二期趋势数组。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_052_100_000 | 账套不存在 |
| 1_052_100_002 | 无权访问该账套 |
| 1_052_100_005 | 账套尚未完成初始化 |

### 1.2 获得财务指标明细

- **路径**: GET /fms/home/metric-detail
- **权限**: fms:home:query
- **说明**: 获得指定财务指标的明细数据，包括指标名称、最近十二期金额趋势和当期科目构成。

**请求参数 (Query 参数)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| accountSetId | Long | 是 | @NotNull | 账套编号 |
| metricKey | String | 是 | @NotBlank | 财务指标标识，如 `income` |

**响应**: CommonResult&lt;FmsHomeMetricDetailRespVO&gt;

| 字段 | 类型 | 说明 |
|-----|------|------|
| key | String | 指标标识 |
| name | String | 指标名称 |
| trends | List&lt;Trend&gt; | 最近十二期指标趋势数组 |
| structure | List&lt;Structure&gt; | 当期科目构成数组 |

Trend 结构：

| 字段 | 类型 | 说明 |
|-----|------|------|
| month | String | 会计期间 |
| amount | BigDecimal | 指标金额 |

Structure 结构：

| 字段 | 类型 | 说明 |
|-----|------|------|
| subjectId | Long | 科目编号 |
| subjectCode | String | 科目编码 |
| subjectName | String | 科目名称 |
| amount | BigDecimal | 科目金额 |

**业务逻辑**:
1. 校验当前用户对账套的读权限。
2. 校验财务指标：按 `metricKey` 在账套已启用指标（无配置时回退到内置五项指标）中查找，找不到时抛出 `HOME_METRIC_INVALID`。
3. 校验账套初始化状态：未初始化或未设置启用期间时抛出 `ACCOUNT_SET_NOT_INITIALIZED`。
4. 确定当前会计期间，逐月计算最近十二期指标金额（早于账套启用期间的月份金额为 0）：行次公式按利润表或资产负债表行次数据汇总；科目公式按科目余额与取数规则计算。
5. 当期（最新一期）明细：行次公式指标按类型查询当期利润表或资产负债表的行次项目数组；科目公式指标则按公式解析各科目金额，构建当期科目构成。
6. 科目构成汇总：行次公式递归展开报表行的公式（防止行次循环引用），按科目汇总当期金额；科目公式按科目编号累加金额，负数运算符取反；两种方式均仅保留正数构成并按金额从大到小排序。
7. 返回指标标识、名称、十二期趋势和当期科目构成数组。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_052_100_000 | 账套不存在 |
| 1_052_100_002 | 无权访问该账套 |
| 1_052_100_005 | 账套尚未完成初始化 |
| 1_052_108_001 | 首页财务指标不正确 |
