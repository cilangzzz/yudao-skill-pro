# 知识库回收站接口 (PmsKnowledgeRecycleController)

> 提供 PMS 知识库的回收站能力：已删除知识库与内容（文件夹/文档/文件）的查询、详情、只读预览、恢复与彻底删除；删除动作本身由知识库、文件夹、文档域在删除时写入回收站记录（`pms_knowledge_recycle_record`），另有 Quartz Job 调用 `deleteExpiredRecycleRecords` 按 30 天到期自动物理清理。

## 接口路径前缀

/pms/kb/recycle  (Controller: PmsKnowledgeRecycleController)

## 1. 回收站查询

### 1.1 获得已删除知识库列表

- **路径**: GET /pms/kb/recycle/library-list
- **权限**: pms:kb:library:delete
- **说明**: 获得当前登录用户显式删除、仍停留在回收站的知识库列表（级联内容不单独成记录）。

**请求参数**: 无

**响应**: CommonResult\<List\<PmsKnowledgeRecycleRespVO\>\>

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 回收站记录编号 |
| libraryId | Long | 知识库编号 |
| type | Integer | 对象类型（1=知识库、2=文件夹、3=文档、4=文件） |
| entityId | Long | 对象编号 |
| name | String | 对象名称 |
| fileSize | Long | 文件大小，单位：字节（仅文件类型，取自文档记录） |
| deleteUserId | Long | 删除人用户编号 |
| deleteUserName | String | 删除人姓名 |
| deleteTime | LocalDateTime | 删除时间 |
| parentId | Long | 父对象编号，回收站详情中用于组装层级 |
| folderId | Long | 所属文件夹编号，回收站详情中用于组装层级 |

**业务逻辑**:
1. 按对象类型「知识库」+ 删除人 = 当前登录用户查询回收站记录列表。
2. 批量查询删除人昵称，拼接 `deleteUserName`。
3. 批量查询文件类型记录对应的知识库文档，拼接 `fileSize`（非文件类型无该字段）。

### 1.2 获得知识库最近删除内容

- **路径**: GET /pms/kb/recycle/content-list
- **权限**: pms:kb:library:delete
- **说明**: 获得指定知识库下最近删除的文件夹/文档/文件回收站记录，仅展示当前用户仍有删除权限的记录。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| libraryId | Long | 是 | @RequestParam(required) | 知识库编号 |

**响应**: CommonResult\<List\<PmsKnowledgeRecycleRespVO\>\>（字段同 1.1）

**业务逻辑**:
1. 校验当前用户对知识库可读（私密库需为成员）。
2. 查询该知识库的全部回收站记录，并排除「知识库」类型记录（库自身记录由 1.1 展示）。
3. 按记录类型批量解析对应文件夹/文档的内容权限编号。
4. 批量计算当前用户对各项内容的内容权限等级，过滤出仍可删除（`canDelete`）的记录返回。

**错误码**:

| 错误码 | 说明 |
|--------|------|
| 1_053_130_000 | 知识库不存在 |
| 1_053_130_001 | 无权访问该知识库 |

### 1.3 获得知识库最近删除详情

- **路径**: GET /pms/kb/recycle/content-detail
- **权限**: pms:kb:library:delete
- **说明**: 获得一条回收站记录的根信息及其本次级联删除的子树（平铺结构，前端按 parentId/folderId 渲染递归树）。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| id | Long | 是 | @RequestParam(required) | 回收站记录编号 |

**响应**: CommonResult\<PmsKnowledgeRecycleDetailRespVO\>

| 字段 | 类型 | 说明 |
|------|------|------|
| root | PmsKnowledgeRecycleRespVO | 根回收站记录（字段同 1.1） |
| children | List\<Item\> | 级联删除内容（不含根对象自身） |

children（Item）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 内容编号 |
| type | Integer | 内容类型（2=文件夹、3=文档、4=文件） |
| name | String | 内容名称 |
| parentId | Long | 父文档或父文件夹编号 |
| folderId | Long | 所属文件夹编号 |
| deleteTime | LocalDateTime | 删除时间 |

**业务逻辑**:
1. 复用回收站列表的权限校验：记录必须存在、不能是「知识库」类型、当前用户对该内容仍具备删除权限，避免详情接口绕过权限边界。
2. 查询知识库内仍处于回收状态的全部文件夹和文档。
3. 按根对象关系解析级联子树：文件夹记录取其全部后代文件夹；文档/文件记录取其全部后代文档；文件夹记录同时收集子树内挂载的文档。
4. 组装根记录 + 级联节点（文件夹与文档平铺）的详情返回，根对象自身不出现在 children 中。

**错误码**:

| 错误码 | 说明 |
|--------|------|
| 1_053_130_000 | 知识库不存在 |
| 1_053_130_001 | 无权访问该知识库 |
| 1_053_130_040 | 知识库回收站记录不存在 |
| 1_053_130_041 | 知识库回收站对象类型无效 |
| 1_053_130_073 | 无权删除该知识内容 |

### 1.4 预览知识库最近删除内容

- **路径**: GET /pms/kb/recycle/content-preview
- **权限**: pms:kb:library:delete
- **说明**: 只读预览回收站中文档/文件的正文或文件地址，可指定级联子树中的某个实体；文件夹不支持预览。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| id | Long | 是 | @RequestParam(required) | 回收站记录编号 |
| entityId | Long | 否 | 无校验注解 | 要预览的实体编号（缺省预览记录根对象） |

**响应**: CommonResult\<PmsKnowledgeRecyclePreviewRespVO\>

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 内容编号 |
| type | Integer | 内容类型 |
| name | String | 内容名称（取文档标题） |
| content | String | 文档正文或文件地址 |
| fileType | String | 文件类型，如 pdf |
| fileSize | Long | 文件大小，单位：字节 |

**业务逻辑**:
1. 复用回收站内容权限校验（记录存在、非知识库类型、当前用户可删除），避免通过预览接口读取无权限内容。
2. 未传 `entityId` 时预览记录根对象；传入且与根对象不同时，从详情级联子树中定位该实体，找不到则抛回收站记录不存在。
3. 目标为文件夹类型时抛「回收站对象类型无效」，文件夹不提供预览。
4. 查询原文档数据（回收站保留原文档记录）返回，文档不存在则抛回收站记录不存在；Controller 将文档标题映射为 `name`。

**错误码**:

| 错误码 | 说明 |
|--------|------|
| 1_053_130_000 | 知识库不存在 |
| 1_053_130_001 | 无权访问该知识库 |
| 1_053_130_040 | 知识库回收站记录不存在 |
| 1_053_130_041 | 知识库回收站对象类型无效 |
| 1_053_130_073 | 无权删除该知识内容 |

## 2. 回收站恢复与彻底删除

### 2.1 恢复回收站对象

- **路径**: PUT /pms/kb/recycle/restore
- **权限**: pms:kb:library:delete
- **说明**: 按回收站记录恢复知识库、文件夹或文档及其级联删除的子树，恢复成功后删除该回收站记录。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| id | Long | 是 | @RequestParam(required) | 回收站记录编号 |

**响应**: CommonResult\<Boolean\>（data 恒为 true，无字段表）

**业务逻辑**:
1. 校验回收站记录存在，且对象类型为知识库/文件夹/文档/文件之一（未知类型直接报错）。
2. 知识库类型：校验当前用户为知识库创建人、知识库管理员或系统超级管理员，恢复知识库主记录，并恢复随库级联删除的文件夹与文档（排除此前被单独删除、仍受其他回收站记录保护的子树）。
3. 文件夹类型：校验内容删除权限，恢复文件夹及其子树；若原父文件夹仍处于删除状态，则将该根文件夹恢复挂载到知识库根目录。
4. 文档/文件类型：校验内容删除权限，恢复根文档及其全部子文档（排除被单独删除的子文档树）；原目录或父文档尚未恢复时，将根文档挂载到知识库根目录。
5. 事务内删除本次回收站记录。

**错误码**:

| 错误码 | 说明 |
|--------|------|
| 1_053_130_000 | 知识库不存在（待恢复知识库不在回收站状态等） |
| 1_053_130_001 | 无权访问该知识库 |
| 1_053_130_003 | 只有知识库管理员可以执行该操作 |
| 1_053_130_040 | 知识库回收站记录不存在 |
| 1_053_130_041 | 知识库回收站对象类型无效 |
| 1_053_130_073 | 无权删除该知识内容 |

### 2.2 彻底删除回收站对象

- **路径**: DELETE /pms/kb/recycle/permanent-delete
- **权限**: pms:kb:library:delete
- **说明**: 将回收站对象物理删除（不可恢复），知识库类型级联清除全部内容、成员与关联数据，内容类型级联清除子树及其互动数据。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| id | Long | 是 | @RequestParam(required) | 回收站记录编号 |

**响应**: CommonResult\<Boolean\>（data 恒为 true，无字段表）

**业务逻辑**:
1. 校验回收站记录存在，且对象类型合法。
2. 知识库类型：校验当前用户为知识库创建人、知识库管理员或系统超级管理员；依次物理删除收藏、点赞、浏览记录、分享、评论、文档、文件夹、内容权限、全部回收站记录、知识库分组关系、成员关系，最后删除知识库主记录。
3. 文件夹类型：校验内容删除权限；解析文件夹子树及其中文档，物理删除收藏、点赞、浏览、分享、评论、文档与文件夹主记录，清理不再被引用的内容权限及对应文件夹/文档/文件回收站记录。
4. 文档/文件类型：校验内容删除权限；解析文档子树，物理删除互动数据（收藏、点赞、浏览、分享、评论）与文档主记录，清理未引用的内容权限及对应回收站记录。

**错误码**:

| 错误码 | 说明 |
|--------|------|
| 1_053_130_000 | 知识库不存在 |
| 1_053_130_001 | 无权访问该知识库 |
| 1_053_130_003 | 只有知识库管理员可以执行该操作 |
| 1_053_130_040 | 知识库回收站记录不存在 |
| 1_053_130_041 | 知识库回收站对象类型无效 |
| 1_053_130_073 | 无权删除该知识内容 |
