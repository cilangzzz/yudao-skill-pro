# 企业云盘接口 (OaFileNodeController / OaFileFavoriteController / OaFilePermissionController)

> 企业云盘以「文件节点树」为核心，提供个人文件的目录管理（创建、重命名、移动、复制、回收站）、云盘容量统计、按用户/部门的共享权限（支持继承与有效期）以及收藏能力；文件实体存储复用 Infra 文件服务，仅在具备下载权限时按需签发临时访问地址。

## 接口路径前缀

- /oa/file-node (Controller: OaFileNodeController)
- /oa/file-favorite (Controller: OaFileFavoriteController)
- /oa/file-permission (Controller: OaFilePermissionController)

---

## 1. 云盘文件节点（OaFileNodeController）

### 1.1 获得本人云盘空间

- **路径**: GET /oa/file-node/get-storage
- **权限**: oa:file:query
- **说明**: 统计本人已用容量、总容量及文件/共享/收到的共享数量。

**请求参数**: 无

**响应**: CommonResult&lt;OaFileStorageRespVO&gt;

| 字段 | 类型 | 说明 |
|-----|------|------|
| usedSize | Long | 已用容量，单位字节（回收站文件仍占用容量） |
| totalSize | Long | 总容量，单位字节（来自 `oa.file.storage-size` 配置，默认 5 GB） |
| fileCount | Long | 本人正常文件数量，不含目录和回收站 |
| sharedCount | Long | 本人有效共享节点数量，按文件或目录去重 |
| receivedCount | Long | 收到的共享入口数量，不重复统计子节点 |

**业务逻辑**:
1. 数据库汇总本人创建的文件总大小（回收站文件仍计入占用）。
2. 查询本人正常状态节点，并叠加「共享给本人」的候选节点（含用户授权、部门授权及目录继承范围）。
3. 批量补齐候选节点的全部祖先，查询相关节点的共享授权并过滤已过期授权。
4. 逐个统计：本人文件数、本人已共享且授权有效的节点数；共享目录下的子节点只统计一个入口，与共享列表口径一致。
5. 返回已用容量、配置的总容量及三个统计数量。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |

### 1.2 获得云盘文件分页

- **路径**: GET /oa/file-node/page
- **权限**: oa:file:query
- **说明**: 按 scope（我的文件/共享/收藏/回收站）分页查询文件与目录，返回当前用户有效权限级别与收藏状态。

**请求参数 (OaFileNodePageReqVO)**（继承 PageParam）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| pageNo | Integer | 是 | @NotNull、@Min(1) | 页码，从 1 开始，默认 1 |
| pageSize | Integer | 是 | @NotNull、@Min(1)、@Max(200) | 每页条数，默认 10 |
| scope | String | 是 | @NotBlank、@InEnum(OaFileScopeEnum) | 列表范围：my（我的文件）、shared（共享文件）、favorite（我的收藏）、recycle（回收站） |
| parentId | Long | 否 | — | 父目录编号，不传时查询范围内全部文件（根目录传 0） |
| name | String | 否 | @Size(max = 255) | 名称模糊搜索 |
| category | Integer | 否 | @InEnum(OaFileCategoryEnum) | 文件分类：1 图片、2 文档、3 视频、4 音频、5 压缩包、6 其他 |
| createTime | LocalDateTime[] | 否 | @DateTimeFormat(yyyy-MM-dd HH:mm:ss) | 创建时间范围 |

**响应**: CommonResult&lt;PageResult&lt;OaFileNodeRespVO&gt;&gt;

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | Long | 节点编号 |
| parentId | Long | 父目录编号 |
| type | Integer | 节点类型：0 文件夹、1 文件 |
| name | String | 名称 |
| url | String | 临时文件地址（列表中恒为空，预览和下载统一走详情接口授权） |
| extension | String | 扩展名 |
| category | Integer | 文件分类：1 图片、2 文档、3 视频、4 音频、5 压缩包、6 其他 |
| size | Long | 大小，单位字节 |
| status | Integer | 节点状态：0 正常、1 回收站 |
| creator | String | 创建人（用户编号） |
| createTime | LocalDateTime | 创建时间 |
| updateTime | LocalDateTime | 更新时间 |
| level | Integer | 当前用户权限级别：0 无权限、1 只读、2 下载、3 编辑、4 管理 |
| favorite | Boolean | 是否收藏 |

**业务逻辑**:
1. 指定 parentId 且非根目录时，先校验目标目录及祖先可见且本人具备只读权限（回收站范围除外）。
2. 「我的文件」根目录或已校验的本人目录下，正常子节点直接走数据库分页。
3. 「收藏」入口提前查询本人收藏编号用于筛选，收藏为空直接返回空页。
4. 数据库筛选候选节点并批量补齐祖先（祖先仅用于判权）；「共享」根入口按用户/部门有效授权及可继承目录逐层计算候选集。
5. 按可见范围逐条筛选：回收站只展示本人回收根节点（不重复展示被遮蔽的子节点）；普通范围要求有效权限级别大于无权限；my 范围排除他人节点、shared 范围排除本人节点、favorite 范围仅保留收藏节点；指定目录时仅保留直接子节点。
6. 文件夹优先、同类型按创建时间及编号倒序排序，内存分页保证结果稳定。
7. 仅转换当前页并补充收藏状态与权限级别；列表不暴露原始文件地址。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |

### 1.3 获得本人可用目录列表

- **路径**: GET /oa/file-node/directory-list
- **权限**: oa:file:query
- **说明**: 查询本人创建的正常状态目录（含其祖先链），用于目录树选择。

**请求参数**: 无

**响应**: CommonResult&lt;List&lt;OaFileNodeRespVO&gt;&gt;（字段同 1.2 响应）

**业务逻辑**:
1. 查询本人创建的正常状态目录节点。
2. 批量补齐各目录的祖先节点（不加载文件）。
3. 筛选路径可用的目录（自身及祖先均正常、无断链和循环路径）并转换响应，url 置空。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |

### 1.4 创建云盘文件或目录

- **路径**: POST /oa/file-node/create
- **权限**: oa:file:create
- **说明**: 前端完成文件上传后登记文件信息，或在目录下新建文件夹。

**请求参数 (OaFileNodeSaveReqVO)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| parentId | Long | 是 | @NotNull | 父目录编号（根目录传 0） |
| type | Integer | 是 | @NotNull、@InEnum(OaFileNodeTypeEnum) | 节点类型：0 文件夹、1 文件 |
| name | String | 是 | @NotBlank、@Size(max = 255) | 节点名称 |
| url | String | 条件 | @Size(max = 2048)、@AssertTrue（文件类型必填） | 上传文件地址，文件夹不传 |
| size | Long | 条件 | @AssertTrue（文件类型必填且 ≥ 0） | 文件大小，单位字节，文件夹不传 |

**响应**: CommonResult&lt;Long&gt;（新节点编号）

**业务逻辑**:
1. 非根目录时锁定父目录，校验本人对其具备编辑权限，且目标必须是目录类型。
2. 文件类型登记前校验本人剩余云盘容量（回收站文件仍计入占用），不足则报容量不足。
3. 保存节点：文件类型按扩展名计算文件分类，并登记上传地址与大小；目录类型大小为 0。
4. 目标目录存在同名正常节点时自动追加序号（追加在扩展名前）。
5. 记录创建人部门编号后插入节点。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |
| 1_054_230_009 | 云盘剩余容量不足，请清理文件后重试 |

### 1.5 重命名云盘文件

- **路径**: PUT /oa/file-node/update-name
- **权限**: oa:file:update
- **说明**: 重命名节点，文件分类随新扩展名同步更新。

**请求参数 (OaFileNodeRenameReqVO)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @NotNull | 节点编号 |
| name | String | 是 | @NotBlank、@Size(max = 255) | 新名称 |

**响应**: CommonResult&lt;Boolean&gt;（操作结果）

**业务逻辑**:
1. 锁定节点并校验本人具备编辑权限。
2. 计算可用名称：排除自身后与同级正常节点比较，同名时自动追加序号。
3. 更新名称；文件类型随新扩展名更新扩展名与文件分类。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |

### 1.6 移动云盘文件

- **路径**: PUT /oa/file-node/update-parent
- **权限**: oa:file:update
- **说明**: 将本人节点移动到目标目录，子树保持原有结构。

**请求参数 (OaFileNodeMoveReqVO)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @NotNull | 节点编号 |
| parentId | Long | 是 | @NotNull | 目标目录编号（根目录传 0） |

**响应**: CommonResult&lt;Boolean&gt;（操作结果）

**业务逻辑**:
1. 按编号锁定本人全部目录，串行化目录移动校验，防止两个目录并发互移形成环。
2. 锁定目标节点并校验本人具备编辑权限。
3. 校验节点归属，只允许移动本人创建的节点。
4. 非根目录时校验目标目录的编辑权限、归属及目录类型，并沿父链检查不能移动到自身或其子目录。
5. 目标目录同名时自动追加序号（排除当前节点）。
6. 更新父目录和名称，子树保持原有结构。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |
| 1_054_230_005 | 不能移动到自身或子目录 |

### 1.7 复制云盘文件或目录

- **路径**: POST /oa/file-node/copy
- **权限**: oa:file:create
- **说明**: 复制本人或共享给自己的节点到目标目录，目录类型递归复制整个子树。

**请求参数 (OaFileNodeCopyReqVO)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @NotNull | 源节点编号 |
| parentId | Long | 是 | @NotNull | 目标目录编号（根目录传 0） |

**响应**: CommonResult&lt;Long&gt;（新根节点编号）

**业务逻辑**:
1. 校验源节点具备下载权限（仅正常节点可复制）。
2. 非根目录时锁定并校验目标目录为本人所有且具备编辑权限、类型为目录，且不能复制到源目录自身或其下级目录。
3. 按层读取源子树，跳过回收站节点，复制前逐个校验每个节点的下载权限。
4. 为副本根节点生成不重名的名称（保留扩展名）。
5. 逐层批量插入新节点树；副本不继承原创建人、共享权限和收藏，底层文件由 Infra 文件服务复用。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |
| 1_054_230_009 | 云盘剩余容量不足，请清理文件后重试 |

### 1.8 移入回收站

- **路径**: PUT /oa/file-node/recycle
- **权限**: oa:file:delete
- **说明**: 将本人节点移入回收站，仅改变当前节点状态，不递归回收子节点。

**请求参数 (Query)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | — | 节点编号 |

**响应**: CommonResult&lt;Boolean&gt;（操作结果）

**业务逻辑**:
1. 锁定节点并校验节点存在且处于正常状态。
2. 校验节点属于本人。
3. 仅将当前节点状态改为回收站，保留子节点原有状态。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_003 | 无权操作该文件或目录 |

- **权限**: oa:file:delete
- **说明**: 逻辑删除回收站中的节点，同时清理其共享权限与收藏。

**请求参数 (Query)**

### 1.11 获得文件详情

- **路径**: GET /oa/file-node/get
- **权限**: oa:file:query
- **说明**: 获得节点详情；文件类型且具备下载权限时返回临时下载地址。

**请求参数 (Query)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | — | 节点编号 |

**响应**: CommonResult&lt;OaFileNodeRespVO&gt;（字段同 1.2 响应；url 仅在文件类型且权限级别 ≥ 下载时签发临时地址，有效期由 `oa.file.download-url-expire-seconds` 配置，默认 300 秒）

**业务逻辑**:
1. 校验节点存在，且自身及祖先均处于正常状态（拒绝通过编号直接访问回收目录中的文件，并排除断链与循环路径）。
2. 计算当前用户有效权限级别（本人创建即为管理；否则沿父链叠加用户/部门授权，仅统计未过期且允许继承的授权），低于只读权限则拒绝访问。
3. 查询当前用户对该节点的收藏状态。
4. 拼接详情并补充权限级别与收藏状态。
5. 仅文件类型且具备下载权限时，通过 Infra FileApi 签发临时下载地址。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |

## 2. 云盘收藏（OaFileFavoriteController）

### 2.1 收藏文件

- **路径**: POST /oa/file-favorite/create
- **权限**: oa:file:query
- **说明**: 收藏一个本人可见（只读及以上权限）的节点，重复收藏幂等。

**请求参数 (Query)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|

### 2.2 取消收藏文件

- **路径**: DELETE /oa/file-favorite/delete
- **权限**: oa:file:query
- **说明**: 删除本人对指定节点的收藏记录。

**请求参数 (Query)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| nodeId | Long | 是 | — | 节点编号 |

**响应**: CommonResult&lt;Boolean&gt;（操作结果）

**业务逻辑**:
1. 按节点编号和当前用户删除本人收藏记录（不存在时不报错）。

## 3. 云盘共享权限（OaFilePermissionController）

### 3.1 获得文件共享权限

- **路径**: GET /oa/file-permission/list
- **权限**: oa:file:share
- **说明**: 查询指定节点上配置的全部共享权限，仅管理权限可见。

**请求参数 (Query)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| nodeId | Long | 是 | — | 节点编号 |

**响应**: CommonResult&lt;List&lt;OaFilePermissionRespVO&gt;&gt;

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | Long | 权限编号 |
| nodeId | Long | 节点编号 |
| subjectType | Integer | 共享主体类型：1 用户、2 部门 |
| subjectId | Long | 主体编号（用户或部门编号） |
| level | Integer | 权限级别：1 只读、2 下载、3 编辑、4 管理 |
| inherit | Boolean | 是否继承到子目录及文件 |
| expireTime | LocalDateTime | 到期时间（为空表示永久有效） |

**业务逻辑**:
1. 校验本人对节点具备管理权限。
2. 查询该节点的全部共享权限记录。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |

### 3.2 保存文件共享权限

- **路径**: POST /oa/file-permission/save
- **权限**: oa:file:share
- **说明**: 为节点新增或更新一个用户/部门的共享权限（同节点同主体仅保留一条）。

**请求参数 (OaFilePermissionSaveReqVO)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| nodeId | Long | 是 | @NotNull | 节点编号 |
| subjectType | Integer | 是 | @NotNull、@InEnum(OaFileSubjectTypeEnum) | 共享主体类型：1 用户、2 部门 |
| subjectId | Long | 是 | @NotNull | 主体编号（用户或部门编号） |
| level | Integer | 是 | @NotNull、@InEnum(OaFilePermissionLevelEnum) | 权限级别：1 只读、2 下载、3 编辑、4 管理 |
| inherit | Boolean | 是 | @NotNull | 是否继承到子目录及文件 |
| expireTime | LocalDateTime | 否 | @Future | 到期时间，必须晚于当前时间；为空表示永久有效 |

**响应**: CommonResult&lt;Long&gt;（权限编号）

**业务逻辑**:
1. 锁定节点并校验本人具备管理权限。
2. 校验共享主体真实存在：用户类型校验用户、部门类型校验部门，其他类型直接拒绝。
3. 已存在同节点同主体的权限记录时更新该记录，否则新增。
4. 返回权限编号。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |

### 3.3 取消文件共享权限

- **路径**: DELETE /oa/file-permission/delete
- **权限**: oa:file:share
- **说明**: 删除一条共享权限记录，要求对对应节点具备管理权限。

**请求参数 (Query)**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | — | 权限编号 |

**响应**: CommonResult&lt;Boolean&gt;（操作结果）

**业务逻辑**:
1. 校验共享记录存在，不存在报「共享权限不存在」。
2. 校验本人对该权限所属节点具备管理权限。
3. 逻辑删除共享记录。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_230_000 | 文件或目录不存在 |
| 1_054_230_001 | 文件或所属目录已在回收站 |
| 1_054_230_002 | 文件目录结构异常或所属目录已删除 |
| 1_054_230_003 | 无权操作该文件或目录 |
| 1_054_230_008 | 共享权限不存在 |
