# OA 笔记接口 (OaNoteController)

> 提供个人笔记的创建、编辑、收藏、共享（多人持有）与笔记目录管理，创建人和共享接收人通过"持有关系"访问笔记。

## 接口路径前缀

- /oa/note  (Controller: OaNoteController)
- /oa/note-category  (Controller: OaNoteCategoryController)

## 1. 笔记管理（OaNoteController，前缀 /oa/note）

### 1.1 创建笔记

- **路径**: POST /oa/note/create
- **权限**: oa:note:create
- **说明**: 在指定目录下创建一篇笔记，并建立创建人的持有关系。

**请求参数 (OaNoteSaveReqVO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 否 | - | 笔记编号（新增时不传） |
| categoryId | Long | 否 | - | 目录编号 |
| type | Integer | 是 | @NotNull、@InEnum(OaNoteTypeEnum) | 笔记类型：1 我的笔记、2 公司笔记、3 共享笔记 |
| priority | Integer | 是 | @NotNull、@InEnum(OaPriorityEnum)、@Max(2) | 优先级：1 一般、2 重要（笔记仅允许一般或重要） |
| title | String | 是 | @NotBlank、@Size(max = 255) | 标题 |
| content | String | 是 | @NotBlank | 内容 |
| fileUrls | List\<String\> | 否 | 元素 @NotBlank、@Size(max = 512) | 附件地址列表 |

**响应**: CommonResult\<Long\> —— 笔记编号

**业务逻辑**:
1. 校验笔记目录属于当前用户（目录不存在或不属于本人时报"笔记目录不存在"）。
2. 新增笔记，收藏状态初始化为 false。
3. 插入创建人的笔记持有关系（创建人也通过持有关系访问笔记）。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_002 | 笔记目录不存在 |

### 1.2 更新笔记

- **路径**: PUT /oa/note/update
- **权限**: oa:note:update
- **说明**: 仅创建人可修改笔记内容及其所属目录。

**请求参数 (OaNoteSaveReqVO)**: 同 1.1（更新时 id 必传）

**响应**: CommonResult\<Boolean\> —— 是否成功

**业务逻辑**:
1. 校验笔记属于当前用户（须仍持有且为创建人，否则报"无权访问该笔记"）。
2. 校验新目录属于当前用户。
3. 更新笔记（fileUrls 为空时会置空原有附件列表）。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_000 | 笔记不存在 |
| 1_054_120_001 | 无权访问该笔记 |
| 1_054_120_002 | 笔记目录不存在 |

### 1.3 删除笔记

- **路径**: DELETE /oa/note/delete
- **权限**: oa:note:delete
- **说明**: 创建人删除笔记；共享笔记仅退出本人持有，不删除正文。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @RequestParam 必填 | 笔记编号 |

**响应**: CommonResult\<Boolean\> —— 是否成功

**业务逻辑**:
1. 校验笔记属于当前用户（须仍持有且为创建人）。
2. 若为共享笔记（类型为共享，或存在其他接收人），仅删除本人持有关系，保留正文及其他接收人的访问。
3. 否则（私密笔记）先删除全部接收关系，再删除笔记本身。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_000 | 笔记不存在 |
| 1_054_120_001 | 无权访问该笔记 |

### 1.4 移除收到的共享笔记

- **路径**: DELETE /oa/note/delete-received
- **权限**: 已认证（仅登录，未配置 @PreAuthorize）
- **说明**: 共享接收人从"共享给我"列表中移除该笔记。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @RequestParam 必填 | 笔记编号 |

**响应**: CommonResult\<Boolean\> —— 是否成功

**业务逻辑**:
1. 校验笔记存在；若当前用户是创建人则拒绝（创建人须走本人笔记删除入口）。
2. 校验当前用户是共享接收人，否则拒绝。
3. 仅移除本人的接收关系，保留正文及其他用户的访问权限。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_000 | 笔记不存在 |
| 1_054_120_001 | 无权访问该笔记 |

### 1.5 更新笔记收藏状态

- **路径**: PUT /oa/note/update-favorite
- **权限**: 已认证（仅登录，未配置 @PreAuthorize）
- **说明**: 收藏或取消收藏笔记，持有人共用同一收藏状态。

**请求参数 (OaNoteFavoriteUpdateReqVO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @NotNull | 笔记编号 |
| favorite | Boolean | 是 | @NotNull | 是否收藏 |

**响应**: CommonResult\<Boolean\> —— 是否成功

**业务逻辑**:
1. 校验当前用户仍持有笔记（复用详情查询的持有校验）。
2. 直接更新笔记的收藏状态（所有持有人共享该状态）。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_000 | 笔记不存在 |
| 1_054_120_001 | 无权访问该笔记 |

### 1.6 更新笔记共享接收人

- **路径**: PUT /oa/note/update-share
- **权限**: oa:note:update
- **说明**: 全量设置笔记的共享接收人，空列表表示取消全部共享。

**请求参数 (OaNoteShareUpdateReqVO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @NotNull | 笔记编号 |
| receiverUserIds | List\<Long\> | 是 | @NotNull、元素 @NotNull | 接收人用户编号列表，空列表表示取消全部共享 |

**响应**: CommonResult\<Boolean\> —— 是否成功

**业务逻辑**:
1. 校验笔记属于当前用户（须仍持有且为创建人）。
2. 校验接收人用户均存在（调用 system 模块 AdminUserApi 校验）。
3. 查询原接收关系，与新接收集合（自动补入创建人自身）计算差异。
4. 批量新增新增的接收关系，删除被取消的接收关系（创建人自身关系不参与撤销，清空共享名单仍保留创建人的持有关系）。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_000 | 笔记不存在 |
| 1_054_120_001 | 无权访问该笔记 |

### 1.7 获得笔记详情

- **路径**: GET /oa/note/get
- **权限**: oa:note:query
- **说明**: 获取单个笔记详情，创建人和接收人均可访问。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @RequestParam 必填 | 笔记编号 |

**响应**: CommonResult\<OaNoteRespVO\>

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | Long | 笔记编号 |
| creatorUserId | Long | 创建人用户编号 |
| creatorUserName | String | 创建人用户昵称 |
| categoryId | Long | 目录编号 |
| categoryName | String | 目录名称 |
| type | Integer | 笔记类型：1 我的笔记、2 公司笔记、3 共享笔记 |
| priority | Integer | 优先级：1 一般、2 重要 |
| title | String | 标题 |
| content | String | 内容 |
| favorite | Boolean | 是否收藏 |
| fileUrls | List\<String\> | 附件地址列表 |
| receiverUserIds | List\<Long\> | 接收人用户编号列表（不含创建人） |
| receiverUserNames | List\<String\> | 接收人用户昵称列表 |
| createTime | LocalDateTime | 创建时间 |

**业务逻辑**:
1. 校验笔记存在。
2. 校验当前用户仍持有笔记（创建人和接收人均通过持有关系访问，否则报"无权访问该笔记"）。
3. 拼接展示字段：创建人昵称、目录名称、接收人列表（共享名单仅展示除创建人外的其他接收人）。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_000 | 笔记不存在 |
| 1_054_120_001 | 无权访问该笔记 |

### 1.8 获得我的笔记分页

- **路径**: GET /oa/note/my-page
- **权限**: oa:note:query
- **说明**: 分页返回本人创建且仍持有的笔记。

**请求参数 (OaNotePageReqVO，继承 PageParam)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| pageNo | Integer | 是 | @NotNull、@Min(1) | 页码，从 1 开始 |
| pageSize | Integer | 是 | @NotNull、@Min(1)、@Max(200) | 每页条数 |
| title | String | 否 | - | 标题（模糊匹配） |
| categoryId | Long | 否 | - | 目录编号 |
| type | Integer | 否 | @InEnum(OaNoteTypeEnum) | 笔记类型 |
| priority | Integer | 否 | @InEnum(OaPriorityEnum) | 优先级 |
| favorite | Boolean | 否 | - | 是否收藏 |
| createTime | LocalDateTime[] | 否 | @DateTimeFormat(yyyy-MM-dd HH:mm:ss) | 创建时间范围 |

**响应**: CommonResult\<PageResult\<OaNoteRespVO\>\>，OaNoteRespVO 字段同 1.7

**业务逻辑**:
1. 查询当前用户的持有关系，得到笔记编号列表，为空直接返回空分页。
2. 分页查询本人创建且仍持有的笔记，按优先级、创建时间、编号倒序排列。

**错误码**: 无（见 1.7 域错误码）

### 1.9 获得共享给我的笔记分页

- **路径**: GET /oa/note/received-page
- **权限**: oa:note:query
- **说明**: 分页返回他人共享给当前用户的笔记。

**请求参数 (OaNotePageReqVO)**: 同 1.8

**响应**: CommonResult\<PageResult\<OaNoteRespVO\>\>，OaNoteRespVO 字段同 1.7

**业务逻辑**:
1. 查询当前用户的持有关系，为空直接返回空分页。
2. 按持有关系中的笔记编号分页查询，并排除本人创建的笔记，过滤条件与排序方式同"我的笔记"。

**错误码**: 无（见 1.7 域错误码）

## 2. 笔记目录管理（OaNoteCategoryController，前缀 /oa/note-category）

### 2.1 创建笔记目录

- **路径**: POST /oa/note-category/create
- **权限**: 已认证（仅登录，未配置 @PreAuthorize，服务层按当前用户隔离数据）
- **说明**: 在当前用户名下创建一个笔记目录。

**请求参数 (OaNoteCategorySaveReqVO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 否 | - | 目录编号（新增时不传） |
| name | String | 是 | @NotBlank、@Size(max = 255) | 目录名称 |
| sort | Integer | 是 | @NotNull | 显示顺序 |

**响应**: CommonResult\<Long\> —— 目录编号

**业务逻辑**:
1. 校验同一用户下目录名称唯一。
2. 新增目录并绑定当前用户。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_003 | 笔记目录名称已存在 |

### 2.2 更新笔记目录

- **路径**: PUT /oa/note-category/update
- **权限**: 已认证（仅登录，未配置 @PreAuthorize，服务层校验目录归属）
- **说明**: 修改本人目录的名称与显示顺序。

**请求参数 (OaNoteCategorySaveReqVO)**: 同 2.1（更新时 id 必传）

**响应**: CommonResult\<Boolean\> —— 是否成功

**业务逻辑**:
1. 校验目录属于当前用户（否则报"笔记目录不存在"）。
2. 校验同一用户下目录名称唯一（排除自身）。
3. 更新目录。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_002 | 笔记目录不存在 |
| 1_054_120_003 | 笔记目录名称已存在 |

### 2.3 删除笔记目录

- **路径**: DELETE /oa/note-category/delete
- **权限**: 已认证（仅登录，未配置 @PreAuthorize，服务层校验目录归属）
- **说明**: 删除本人目录及其下本人创建的笔记。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @RequestParam 必填 | 目录编号 |

**响应**: CommonResult\<Boolean\> —— 是否成功

**业务逻辑**:
1. 校验目录属于当前用户。
2. 删除目录下本人仍持有的笔记（校验均为本人创建，同时删除其接收关系）；已退出的共享正文不随目录删除。
3. 删除目录本身。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_001 | 无权访问该笔记 |
| 1_054_120_002 | 笔记目录不存在 |

### 2.4 获得笔记目录

- **路径**: GET /oa/note-category/get
- **权限**: oa:note:query
- **说明**: 获取单个目录详情，仅限本人的目录。

**请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|-----|------|------|---------|------|
| id | Long | 是 | @RequestParam 必填 | 目录编号 |

**响应**: CommonResult\<OaNoteCategoryRespVO\>

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | Long | 目录编号 |
| name | String | 目录名称 |
| sort | Integer | 显示顺序 |
| createTime | LocalDateTime | 创建时间 |

**业务逻辑**:
1. 校验目录属于当前用户（不存在或不属于本人时报"笔记目录不存在"），校验通过后返回目录信息。

**错误码**:

| 错误码 | 说明 |
|-------|------|
| 1_054_120_002 | 笔记目录不存在 |

### 2.5 获得笔记目录精简列表

- **路径**: GET /oa/note-category/simple-list
- **权限**: 已认证（仅登录，未配置 @PreAuthorize）
- **说明**: 返回当前用户全部目录的编号与名称，用于下拉选择。

**请求参数**: 无

**响应**: CommonResult\<List\<OaNoteCategoryRespVO\>\>，仅包含 id、name 字段（字段说明同 2.4）

**业务逻辑**:
1. 查询当前用户的全部目录并转换为精简结构（仅 id 与 name）。

**错误码**: 无

### 2.6 获得笔记目录列表

- **路径**: GET /oa/note-category/list
- **权限**: oa:note:query
- **说明**: 返回当前用户全部目录的完整信息。

**请求参数**: 无

**响应**: CommonResult\<List\<OaNoteCategoryRespVO\>\>，字段说明同 2.4

**业务逻辑**:
1. 查询当前用户的全部目录并返回完整字段。

**错误码**: 无
